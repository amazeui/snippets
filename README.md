:fa-github-square:https://github.com/amazeui/snippets

下载：[中文Amaze UI Snippets](http://git.oschina.net/Crazy-code/Amaze-UI-Snippets-for-Chinese/repository/archive/master)
## 安装方法
Sublime Text 2/3：打开 <code>Preferences > Browse Packages</code>，在 <code>Browse Packages</code> 下创建 <code>ChineseAmazeUI</code> 目录，把从上面下载的 Sublime 代码片段解压得到的文件复制创建好的 <code>ChineseAmazeUI</code> 目录下。
